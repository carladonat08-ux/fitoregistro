    ¿Qué puedo usar contra…?

    Elige el cultivo y la plaga o finalidad. Verás todos los productos autorizados con su dosis, plazo de seguridad y nº de aplicaciones, ordenables por columna. Se incluyen también los productos registrados para el grupo superior (por ejemplo, «Ácaros» para el ácaro rojo), marcados como uso genérico.

    Plaga o finalidad

      Verificar una lista de productos

      Pega los productos de una receta, un cuaderno de campo o un parte de tratamientos, uno por línea. Se reconoce el nº de registro (ES-00657, ES00657, 24526) o el nombre comercial. Las líneas sin registro fitosanitario (abonos, correctores, bioestimulantes) quedan separadas. La lista de ejemplo se puede sustituir.

      Mi cuaderno

      Usos que has añadido desde las fichas, con las columnas de tu cuaderno de tratamientos. Puedes descargarlo en Excel o copiarlo para pegarlo en tu hoja. Se guarda solo en este navegador.
